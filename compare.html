Brix — five layouts

1 — Default

half and half

URL
work/brix.html
Reference
None — the site's own
Structure
Label and title take the left half of each section, body takes the right. Figures ignore the split and run full width.
Reading
Alternates between a two-column argument and a full-width image.
Page height
—
Watch
Title and body are the same width, so hierarchy rests on position rather than size. Long titles and long paragraphs compete.
Default

2 — Plain

single column

URL
?plain
Reference
None — project.css alone
Structure
One column. This is what everything else is measured against; ?plain disables the split sheet.
Reading
Nothing to scan by. Section labels are the only landmarks.
Page height
—
Watch
Among the tallest of the five and the least navigable — length with no structure to break it.
?plain

3 — Editorial

16-column

URL
?editorial
Reference
gautiermld.com/projects/freshdirect
Structure
16 columns, 20px gutters. Number at col 2, headline at cols 4–7, body at cols 9–15.
Type
Headline 52/65 serif in a 335px column, so it wraps. Body 16/24 light in a 601px column.
Page height
—
Watch
The rhythm is 200px above a text row and 120px below. That air is the layout; tightening it turns it into an ordinary page.
?editorial

4 — Grid

sticky label rail

URL
?grid
Reference
joseph.cv/azuki
Structure
12 columns. The rail at cols 1–3 holds the label and, under it, the section title in EB Garamond at 20px — both sticky for the length of the section. Body at cols 5–12, figures full width.
Opening
The hero comes first and the project title follows it, in the rail at 15px.
Page height
—
Watch
The rail assumes a one-line label. Every label here measures one line at this width; a longer one needs --gz-rail-label-h raised or it collides with the title.
?grid

5 — Chapter

numbered openers

URL
?chapter
Reference
The Motorola case study image
Structure
Full-width chapter opener — small label over a 30px serif title, with a rule. The numbers come from a CSS counter, so they renumber themselves when a section moves.
Left column
The section's opening paragraph, in the serif at 24px. Body and figures all sit in the right-hand 66%, so a diagram is as wide as the paragraph that introduces it.
Page height
—
Watch
Impact and Exploration have empty left columns — Impact has no paragraph at all, and Exploration's first one sits after its figures. The reference also marks key phrases bold inside grey copy; that has to be written into the copy.
?chapter
