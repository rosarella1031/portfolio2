全部是各库的真实图标文件，从 npm 包里解出来的，不是我画的。都放进真实尺寸的悬浮卡片，垫在 Brix 的浅紫底上；第三个图标是"当前页"状态。

Font Awesome Regular

CC BY 4.0
描边版，但 Free 里只有部分图标有；缺的退回 Solid。

Font Awesome Solid

CC BY 4.0
全实心，最重最满，辨识度最高。

Pixelarticons 没有品牌图标 —— 877 个里不含 GitHub 和 LinkedIn。 这两个用了最接近的通用图标顶替（git-branch、contact），语义和辨识度都明显更弱。真要用像素风，这两个得自己画。
Font Awesome Free 的 Regular（描边）只覆盖一部分图标 —— table-cells 和 cube 没有描边版，只能退回 Solid，所以那一列是混着两种粗细的，不整齐。

Phosphor 三档七个入口全部同源，自带 github-logo、linkedin-logo，还有专门的 read-cv-logo 正好对应 Resume。
